Prediction data and source

Web NMR predicts proton and carbon chemical shifts using a browser port of CDK 2.9's HOSE environment algorithm and the experimental lookup data supplied by nmrshiftdb's standalone predictor jars. Molecular parsing and layout use OpenChemLib. The drawing interface is original Web NMR code and uses no Ketcher code.

Structures and per-molecule calculations remain in your browser. The browser downloads static reference tables from this website when required; there is no prediction backend. Downloaded tables can be reused from browser storage.

What the estimates mean

Matching tries six surrounding spheres down to one, preserving the reference predictor's mean, minimum, maximum and sample count. Fewer matching spheres and broad ranges indicate less specific evidence. Solvent, stereochemistry, conformer populations and diastereotopic protons may remain unresolved. Optional proton splitting uses original first-order simulation with typical, editable J magnitudes (7 Hz vicinal, 8/2/0.5 Hz aromatic ortho/meta/para, and a 12 Hz alkene placeholder). These are estimates, not calculated or database-predicted couplings. OH/NH/SH exchange, geminal/diastereotopic splitting, other long-range and heteronuclear couplings, and second-order effects remain unresolved. Carbon signals are simulated with proton decoupling. Missing environments are reported and omitted; negative shifts are retained.

Equal J values produce normalized Pascal intensities; different J values produce product patterns. Field strength changes ppm spacing while J stays in Hz. Complex Lorentzian line shapes preserve proton area weights. The display uses a bounded, adaptive grid and reports any additional broadening needed to resolve an excessively narrow requested linewidth. Project files preserve the splitting setup, manual J overrides, patterns, and prediction provenance.

The typical coupling hierarchy follows established proton NMR teaching data, including the Hans Reich NMR collection. It is not a fitted coupling model and does not replace measured J values.

Source and licenses

Download application source

The source includes the browser algorithm, original editor and application, tests, and reproducible data extraction utilities. Reference data is distributed as individual compressed chunks. The data manifest provides the exact source hashes, counts and provenance. License and copyright notices are included in the source and the nmrshiftdb license, CDK license and OpenChemLib license.

  • Chemistry Development Kit 2.9 · HOSECodeGenerator and CanonicalLabeler adaptation · LGPL-2.1-or-later.
  • nmrshiftdb standalone predictors · original predictor lookup and experimental reference tables · included AGPL version 3 license.
  • OpenChemLib JS · chemical structure primitives · BSD-3-Clause.

The browser implementation is checked against committed Java reference fixtures. Those checks establish parity on the tested structures, rather than universal accuracy for every molecule.
