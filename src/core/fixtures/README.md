The two `mnova-synthetic-*` fixtures contain only numerical values from a spectrum created for this test. The source signal had 4,096 samples, two Lorentzian peaks (120 at 7.1 ppm, width .025; 35 at 2.3 ppm, width .04), a −.25 baseline and .01 sinusoidal ripple. A fresh single-page Mnova 17 document imported the synthetic JCAMP file and saved native/JSON representations. Only its native compressed array blob and JSON float32 sample bytes were retained. No document, author, computer, acquisition, path, user spectrum, or license metadata is bundled.

The tests wrap that blob in independently authored minimal native records and compare every decoded point. Uncompressed real/complex fixtures are constructed entirely in test code. The optional external-reference tests read private documents outside this source tree and skip if those files are absent.

The `mnova-authored-integrals`, `mnova-authored-peaks`, `mnova-authored-multiplets`, and `mnova-authored-couplings` fixtures contain only framed analysis blocks from a fresh authored Mnova 17 document, using the same synthetic numerical signal. A second control set manual categories dd and q, with J values [7.125, 2.5] and [12.75] Hz. Independent script API output provided expected areas, normalized values, labels, positions, categories, couplings, and nuclide counts. Only the analysis blocks were retained; processing frames preceding the peak list were replaced with authored empty frames. The blocks contain fresh random analysis UUIDs and deliberate synthetic names, with no actor, computer, path, acquisition, license, or private sample metadata.
