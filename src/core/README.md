# Numerical conventions and supported imports

This is an independent TypeScript implementation. It does not use NMRium. Parsing, raw transforms and automatic corrections run inside a browser worker. The output typed-array buffers are transferred back without copying; source arrays in the main application are retained.

## Imports

- Bruker `1r` with matching `procs`; optional `1i`, `fid` and `acqus`. Existing processing is preserved rather than reapplying stored PHC0/PHC1 or windowing. Axes use `OFFSET - index × SW_p / (SI × SF)`. Int32 or float64 are decoded with the declared byte order and `2 ** NC_proc` amplitude scaling. Cropped STSR/STSI processing is explicitly unsupported.
- Bruker complex 1D `fid` with `acqus`, optional `procs`. The declared TD values exclude trailing file padding. AQ_mod 1/3 are accepted; other acquisition modes are rejected. Raw-only data receive a transform with no extra apodization. Frequency referencing uses processing SF when available; otherwise it uses acquisition SFO1 and O1.
- Bruker processed 2D `2rr` with matching `procs` and `proc2s` is supported, including optional `2ri`, `2ir` and `2ii` quadrants. See the 2D section below. Raw `ser` sources are retained for QF, States, States-TPPI and Echo-Antiecho replay. Raw-only imports initially display magnitude; unsupported modes receive an explicit error.
- Folder selection preserves directory names; ZIP expands locally. Multiple independent experiments import as separate spectra. For multiple pdata versions, the first numeric processing version is opened and a warning identifies the choice. Processing-folder `title` files supply `metadata.title` from the first line, `metadata.comments` from subsequent lines and `metadata.sourceTitle` from the complete normalized text; root-level title files are a fallback.
- Text: two columns `ppm,intensity`, optional third imaginary column; CSV, TSV and whitespace separated text are accepted. A first header line is optional. Missing spectrometer frequency remains zero/unknown; J values require user-provided frequency.
- JCAMP-DX: explicit uncompressed AFFN `XYPOINTS` or `XYDATA` with ppm units, factors, and optional `.OBSERVE FREQUENCY`. SQZ/DIF/DUP compression, NTUPLES and unreferenced Hz axes are rejected.
- A 256 MB total expanded import limit and a 4,194,304-point 1D numerical limit protect browser memory. 2D imports have separate matrix and component-memory limits below.

## 2D data and processing

`Spectrum.twoD` stores descending F2 `x` and F1 `y` ppm axes, `width`, `height` and a row-major `real` matrix: `real[rowF1 * width + columnF2]`. Each axis uses its own processing `OFFSET`, `SW_p`, `SI` and `SF`; heteronuclear experiments therefore retain independent calibration. Optional `imagF2`, `imagF1` and `imagBoth` arrays retain converted vendor quadrants. Bruker filenames list F2 first: `imagF2 = -2ir`, `imagF1 = -2ri`, `imagBoth = +2ii`. The single-imaginary signs convert native storage to our positive-FFT convention; real `2rr` is unchanged. See the vendor [TopSpin processing reference](https://imserc.northwestern.edu/downloads/nmr-processing-reference.pdf), sections on hypercomplex data storage. Actual COSY/NOESY Hilbert-axis consistency tests verify both filename assignment and sign. F1 nucleus/frequency and a separate reference offset are included. The compatible 1D `data`/`original` field is an explicitly labelled maximum-absolute-intensity F2 projection with each selected point's sign retained; it is never a flattened matrix or a substitute for 2D analysis.

Processed files are decoded from Bruker `XDIM` submatrix order into full row-major planes, preserving negative intensities and applying the declared endian/type and `2 ** NC_proc` scale. Existing vendor phase/baseline processing is preserved. The supplied NOESY experiment 5 opens as 1024 × 512 with all four quadrants; supplied COSY experiment 4 and the separate COSY folder also open through their processed planes. Both full-plane axes descend from approximately 9.998 ppm for the homonuclear NOESY example. No new absorption phase adjustment is inferred or applied.

Raw `ser` sources are retained alongside immutable processed originals. Processing starts from `twoDOriginal` for native corrections or from unmodified `twoDRaw` when Fourier reprocessing is selected. Uniform complex direct acquisition (`AQ_mod` 1 or 3), declared byte order/type, complete padded rows, and valid `GRPDLY` are required. The engine supports indirect `FnMODE` 1 (QF), 4 (States), 5 (States-TPPI) and 6 (Echo-Antiecho). NUS, TPPI/QSEQ, partial acquisitions and 3D or higher raw data are rejected explicitly. Existing processed planes can still open if their raw mode is unsupported; import explains that replay is unavailable.

Each dimension has independent exponential, Gaussian or sine-bell apodization, and 1/2/4/8 zero filling. Digital-filter correction is optional and applies to each direct FID. Paired States cosine/sine rows are transformed as hypercomplex channels, producing four real planes. States-TPPI alternates entire complex increments; imaginary negation belongs to the separate States-TPPI-N convention and is not applied for FnMODE 5, following the primary [NMRPipe Fourier-transform documentation](https://spin.niddk.nih.gov/bax-apps/NMRPipe/ref/nmrpipe/ft.html). Echo-Antiecho uses the independent Rance-Kay conversion `C = E - A; S = i(E + A)` before the indirect transform. The default is echo-first; the explicit reverse-order option changes indirect orientation and must be chosen for the acquisition. See [NMRPipe's conversion reference](https://spin.niddk.nih.gov/NMRPipe/ref/nmrpipe/coadd.html). Actual supplied experiment 4 agrees with a resolved processed diagonal using echo-first, and experiment 5 has matching States-TPPI axes. Unphased raw COSY can have substantial carrier/edge artifacts; matching a resolved peak does not establish matched vendor processing, amplitudes or quantitative accuracy.

QF has no acquired indirect sine channel. Every stored indirect row is a separate real-valued increment; its transform retains both symmetric F1 responses instead of inventing missing directional information or discarding half the spectrum. Magnitude is recommended and the preview warns about the ambiguity. The [NMRPipe documentation](https://spin.niddk.nih.gov/bax/software/smile/smile_manual.pdf) identifies Bruker QF as magnitude acquisition. Manual phase can rotate the mathematical Fourier components but cannot recover the missing measured quadrature.

Raw-only imports display the norm of the four transformed components, `mode: "magnitude"`. This loses peak signs and phase-sensitive intensity information; import warns accordingly. Enable raw Fourier replay with magnitude disabled to obtain components for reviewable absorption phasing. Acquisition SFO1/O1 supplies calibration when processing SF is unavailable. Native vendor processing and our raw output are not promised to have identical scaling, windows, artifacts or automatic phase.

Phase correction rotates RR/RI and IR/II for F2, or RR/IR and RI/II for F1, using independent PH0/PH1 and referenced pivots. Original quadrants are required for exact rotations. A real-only processed plane can optionally use explicitly enabled discrete-Hilbert analytic quadrature reconstruction. This is a one-sided analytic-spectrum assumption, with finite-range edge artifacts; it does not recover discarded measured complex data. Preview warns when reconstruction is used. Magnitude-only planes cannot be phased; raw replay is required. Automatic phase estimates only the selected axis from its strongest complex row/column, preserving the other axis's recipe. Its positive-absorption objective can invert signed COSY/NOESY features and requires review.

Automatic baseline correction uses the functional 1D method selected independently along F2 rows and F1 columns. Region/exclusion coordinates use referenced ppm. Per-axis manual line anchors use the existing 1D models; three or more noncollinear picked matrix points additionally support a least-squares manual planar surface. The returned full `baseline` matrix is exactly the surface subtracted from RR, for preview and export. Imaginary components are retained. Asymmetric baseline models can remove broad or negative real features; vendor-specific PcBc/apbk remain our documented independent adaptations, not proprietary 2D joint optimizers. Numerical phase/baseline replay is deterministic from its immutable source, and live F1 reference shifts survive both native and raw replay.

Matrices contain at most 10 million elements. Decoded quadrant arrays together must fit 160 MiB; a large full-quadrant dataset can exceed that limit even when `2rr` alone would fit. Importing only `2rr` is supported in that case. Raw processing uses a conservative 160 MiB work-matrix budget. Cropped STSR/STSI planes, inconsistent SI/XDIM or incorrect binary sizes are rejected. Projects retain matrices, quadrants, axes and title/comments and validate finite arrays and dimensions on loading.

Display contour downsampling does not change the full imported data. The overview uses signed extrema in each display bin to retain narrow peaks; nearby weaker opposite-sign peaks can be hidden by a stronger peak in the same bin, and their apparent positions are limited by bin width. Zooming increases the detail sampled from the full matrix. Reference picking searches full-resolution signed local extrema within a bounded ppm radius, returning original row/column and referenced coordinates. This is a reference aid; multiplet picking, volumes, assignment and cross-peak kinetics are not implemented.

## Processing

The complex FFT uses the positive exponential and unscaled amplitude, followed by FFT shift. Its descending ppm coordinate assigns a positive-frequency `exp(+iωt)` FID resonance to the corresponding higher chemical shift. Raw frequency-domain amplitudes and imported vendor processed amplitudes are not promised to be equal without matched vendor scaling.

Bruker group delay advances the integer delay and the declared fractional sample with a centered-frequency Fourier shift, then applies reversed-tail compensation and removes `floor(GRPDLY)+2` samples. Retaining the fractional delay is essential for applying saved phase values. Finite-FID interpolation and tail handling remain an independent approximation, not a claim to reproduce the proprietary filter. A missing/negative legacy delay is rejected; unsupported legacy DECIM/DSPFVS lookup tables are not guessed. See the primary open implementation's [Bruker parameter and correction reference](https://github.com/jjhelmus/nmrglue/blob/master/nmrglue/fileio/bruker.py).

Windows use seconds and Hz: exponential `exp(-π LB t)`, Gaussian `exp(-(π GW t)²/(4 ln 2))`, and an unshifted sine bell over the retained FID. 1D zero filling is a factor of 1/2/4/8/16/32 rounded to a radix-2 size under the four-million-point limit; 2D remains independently limited to 1/2/4/8 per axis. It interpolates the frequency grid without recovering measured information.

Phase follows `S' = S × exp(i × (PH0 + PH1 × (pivot - ppm)/span))`. PH0/PH1 are in degrees; pivot is expressed in referenced ppm in the recipe. Reprocessing starts from the immutable raw or processed source. Real-only 1D imports do not support a complex phase rotation. Saved TopSpin `1i` is conjugated on import to match the positive-FFT imaginary convention; `1r` stays unchanged. Raw-only imports with valid saved phase use `brukerPhaseCorrection`: PH0 = -PHC0, PH1 = -PHC1 × (N-1)/N, pivot at the high-ppm edge plus reference offset. The grid factor converts TopSpin index/N to our endpoint-normalized recipe. Saved windows and supported SI zero filling are initialized separately, and native processed corrections are never reapplied. Actual supplied proton and carbon regressions check full real absorption and complex signal phase against native output; residual vendor baseline/edge/scaling differences remain.

Automatic phase is a bounded coarse-to-fine positive-absorption optimizer, with negative real intensity penalized. It is a reviewable estimate for ordinary positive 1D spectra, not an ACME implementation or a valid automatic treatment for APT/DEPT/signed spectra. The baseline methods and their limitations are documented below; automatic estimates can subtract broad signal features and should be reviewed in the baseline preview.

## Analysis

Peak detection uses the full real array, amplitude threshold, local extrema, parabolic sub-point position refinement and minimum ppm distance. Negative peaks are optional. Signed trapezoidal integration uses actual positive chemical-shift widths and interpolated boundary values; changing reference offsets does not change area. Units are intensity·ppm. Display gain never enters numerical measurements.

Multiplets classify only conservative first-order singlets, doublets, triplets and quartets with approximate spacing and Pascal intensity checks. Other or overlapping patterns remain `m`. Couplings use the actual nucleus frequency in MHz. No molecular assignment, mechanism, higher-order simulation or deconvolution is claimed.

## Public API

`workerClient.ts`: `importBrowserFiles(File[]): Promise<ImportResult>`, `processAsync(Spectrum): Promise<ComplexData>`, `autoPhaseAsync(Spectrum): Promise<{ph0,ph1}>`, `processTwoDAsync(Spectrum): Promise<TwoDProcessingResult>`, `autoPhaseTwoDAsync(Spectrum,"F2"|"F1"): Promise<{ph0,ph1}>`. 2D worker jobs omit redundant current matrices when an original source exists; they preserve current F1 reference metadata.

`imports.ts`: `importEntries(ImportEntry[]): ImportResult`, `parseBrukerParameters(text)`.

`numerics.ts`: `processSpectrum`, `autoPhase`, `detectPeaks(data,offset,thresholdPercent,minDistancePpm,negative?)`, `integrate(data,offset,from,to)`, `analyzeMultiplet(data,offset,from,to,frequencyMHz)`; lower-level `fft`, `applyPhase`, `brukerPhaseCorrection(data,phc0,phc1,referenceOffset?)`, `correctDigitalFilter`, `automaticBaseline`, `nextPowerOfTwo`.

`twoD.ts`: `readRawTwoD(buffer,f2,f1,procs?,proc2s?,experiment?): TwoDRawData`, `readProcessedTwoD`, `processRawTwoDMagnitude`, `decodeTiledPlane`, `processedAxis`, `maximumProjection(twoD, dimension?)` and `extractTwoDSlice(twoD, dimension, position)`. Projection/slice dimensions are `"F2"` or `"F1"`; slice position is the unreferenced ppm coordinate on the other axis.

`twoDProcessing.ts`: `defaultTwoDRecipe(Spectrum)`, `processTwoD(Spectrum): {data,baseline?,warnings}`, `transformRawTwoD(raw,frequencyF2,recipe)`, `autoPhaseTwoD(Spectrum,axis)`, `magnitudeTwoD`, `analyticQuadrature`, `snapTwoDPeak(data,xPpm,yPpm,offsetF2?,radius?:number|[number,number])`. The snapping radius is in ppm, independently per axis; the UI converts a pixel radius. `autoPhaseTwoD` returns absolute recipe phase values for the selected axis.

Tests cover an independently computed analytical DFT, calibrated synthetic raw spectra, signed integrals, endpoint interpolation, phase, baselines, conservative multiplicities and actual supplied Bruker proton/million-point carbon datasets. 2D tests cover independent synthetic tiled binary data, heteronuclear axes, States/States-TPPI peak orientation, actual NOESY/COSY imports, raw-only NOESY agreement with its processed diagonal within 0.08 ppm, malformed matrix rejection and byte-for-byte project roundtrips of every plane/axis. New processing regressions include independent synthetic QF/States/States-TPPI/Echo-Antiecho transforms, actual supplied QF and Echo-Antiecho/NOESY raw sources, all-quadrant rotation, per-axis windows/zero filling, reference replay, explicit Hilbert reconstruction, signed reference snapping, planar/manual and automatic baseline correction, and immutable repeated replay. Practical raw processing still requires review on additional vendor datasets.

## Expanded baseline processing

`processWithBaseline(spectrum)` returns the phased, unbaselined `source`, the fitted `baseline`, corrected `data`, and optional joint `effectivePhase`. The same curve is subtracted on Apply and shown in blue in the UI. Preserve input PH0/PH1 in the recipe: joint automatic phase is replayed deterministically from the original source, and writing effective phase back would run it a second time.

Automatic methods are polynomial and Bernstein robust fits, weighted Whittaker smoothing, splines, ablative peak shaving, arPLS and SNIP. PcBc/apbk are clearly labelled independent phase/baseline adaptations; proprietary vendor objectives and neural weights are not reproduced. Their regional/masked mode disables the global phase adjustment to preserve untreated samples. Manual anchors support linear segments, natural splines, polynomial and Whittaker models. Models use a bounded baseline-estimation grid and are interpolated onto the full spectrum.

Optional recipe fields preserve legacy archive replay. Region limits, excluded regions and anchors use referenced ppm and translate together when referencing/alignment changes. Excluded and out-of-region samples are unchanged. The baseline tests cover all methods, repeat replay, selected/excluded regions, known curves, conditioning and million-point data.

## Native Mnova documents

The modern version-nine dimensional dialect restores exact saved corrected spectra, available complex 1D FIDs, native analysis and independently framed document settings. The fifth essentials double is the acquisition group delay; phase/baseline already reflected in processed samples remain unchanged. Native source arrays are retained separately, so their uncorrected imaginary components never replace corrected output quadrature.

Native 2D complex RI maps to `imagF2`; hypercomplex IR/II map to `imagF1`/`imagBoth`. Uncompressed storage alternates F1 real/imaginary rows with interleaved complex F2 samples. Compressed storage frames RR and RI, a hypercomplex flag, then IR and II. Unlike the Bruker file-name conversion above, native channels keep their stored signs. Bounds include all retained channels and sources within the 160 MiB budget. Files saved real-only receive a specific missing-imaginary explanation; no measured quadrature is fabricated. A native 2D time-domain source cannot be replayed without decoded acquisition quadrature settings.

Saved ppm axes become `savedView`; intensity bounds, canvas coordinates and exact Qt RGB color are retained. Stack order, hidden members and the selected member are explicitly framed collections. Shared intensity bounds are not individual gain values. Individual native gain/delta and freeform publication layouts are currently unverified. Text Report HTML remains inert metadata and has a plain-text counterpart with source geometry. Annotation decoding reads current lists, excludes historical processing snapshots, and preserves native areas/normalization separately from newly computed ppm areas. Unsupported analysis extensions produce specific warnings while available data and other analysis remain usable.

`mnovaNative.ts`: `importMnovaNative(ArrayBuffer,label?): Promise<ImportResult>`; source arrays use `fid` and `nativeSource2D`. Report metadata uses `mnovaReportText`, `mnovaReportHTML`, `mnovaReportCount`, `mnovaReportFrames`. `mnovaNativeDocument.ts` exports bounded axis/stack/text decoders for regression testing. Actual local-reference checks cover all38 corrected spectra/FIDs and all190 integral boundaries/areas/normalizations; authored native controls cover labeled peaks, names and nonzero J. See [the codec build and detailed native scope](../../scripts/mnova-codec/README.md).
