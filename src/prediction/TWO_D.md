HSQC and COSY prediction
=======================

`predictTwoDMolecule` returns a proton `PredictionResult` with atom-linked
`twoD` metadata. Its input adds `experiment`, `hsqcEdited`, `cosyMinJHz`, and
an optional `molecule` document and CDK coupling overrides. Pass the saved
document in original input order to retain permanent drawing IDs. Standalone
notation inputs use deterministic original-position IDs. Structure/document
topology and atom labels are checked before inference.

HSQC requests proton and carbon shifts with existing local prediction engines.
Only directly attached proton/carbon pairs correlate. Heteroatom-bound H,
unprotonated C, deuterium/tritium, and missing shift predictions do not create
HSQC peaks. Individual model Ha/Hb sites retain separate IDs and shifts.
Multiplicity editing gives CH2 the opposite phase to CH/CH3, counting actual
attached 1H from the structure rather than available predicted line count.
Carbon frequency defaults to 0.25145 times the supplied proton frequency.

COSY has proton diagonals and symmetric pairs for nonzero scalar J above the
absolute-J cutoff. The signed J is preserved as provenance; it does not assign
an arbitrary negative COSY phase. Exchangeable-proton transfer and internal
pairs of chemically equivalent protons are omitted. CASCADE requests the
existing FullSSPrUCe J model in first-order mode, avoiding the exact solver's
ten-spin cluster limit. Its 64-explicit-atom/model-support limits still apply.
CDK uses existing typical coupling estimates and manual overrides; grouped
database protons cannot infer stereotopic or geminal H pairs. Zero overrides
remove the corresponding cross peaks.

The 2D map is an illustrative correlation map, not a time-domain pulse-sequence
simulation. Positive transfer weights are proportional to nucleus-group counts
for HSQC and an explicitly heuristic |J| transfer factor for COSY. Transfer
efficiency, pulse timing, relaxation, phase cycling, and strong-coupling fine
structure are not predicted. Gaussian, Lorentzian, or mixed absorption-like
kernels render a finite descending row-major map, capped at 1024 by 1024 points.
Widths broaden to three grid spacings when needed, with the actual widths
reported. Full warnings remain in prediction metadata.

`predictedTwoDSpectrum` saves one spectrum entry with embedded top/left 1D
traces generated by the existing 1D helper. It does not add duplicate list or
kinetics entries. The initial view follows all available H and C shifts and
uses a 1% contour threshold; the full matrix remains available. Correlation
assignments store both ppm coordinates and permanent original atom IDs. Model
or topology mapping changes and changed field/linewidth require recalculation.

Tests exercise direct attachment, missing and quaternary C, edited phase,
explicit H and isotope mapping, Ha/Hb identity, exchangeability, signed and zero
J, symmetry, equivalent spins, cancellation, frequency ratio, bounded finite
maps, and saved assignments/traces. These checks validate the pipeline and
physical correlation selection, not new experimental 2D accuracy.
