# Full-precision native Mnova JPEG 2000 decoder

The browser importer uses a small, local WebAssembly build of **OpenJPEG 2.5.4**, upstream commit `6c4a29b00211eb0430fa0e5e890f1ce5c80f409f`. OpenJPEG is BSD-2-Clause licensed; the complete license is shipped beside the decoder at `src/core/mnovaCodec/LICENSE.OpenJPEG`. The JavaScript runtime is generated by Emscripten 6.0.11; its license is included as `LICENSE.Emscripten`. Both notices are copied into deployed assets at `public/licenses/OpenJPEG.txt` and `public/licenses/Emscripten.txt`. No Mestrelab application code or private sample documents are included.

The source wrapper is `decode.c`; `build.sh` downloads the pinned upstream source, makes the one explicit scientific normalization adjustment, and compiles the shipped assets. Install/activate the official Emscripten SDK, place `emcc`, `emcmake`, `cmake` and Python 3 on PATH, then run:

```sh
bash scripts/mnova-codec/build.sh
npm test -- src/core/mnovaNativeFixtures.test.ts src/core/mnovaNative.test.ts
npm run build
```

The decoder accepts only one unsigned 28-bit component and an independently validated sample count of at most 4,194,304. It has a 256 MiB WASM memory ceiling. The TypeScript reader additionally enforces declared frame sizes, exact counts, finite calibration and samples, and a 160 MiB aggregate retained-array budget. The browser worker initializes WASM only for a compressed native import. The deployed `.wasm` asset is local; uploaded files stay in the browser.

Ordinary image decoders clamp JPEG 2000 samples to the nominal image precision and commonly expose only 8/16-bit output. Mnova uses the floating, centered reconstruction of its 28-bit scientific values, including values outside that image display interval. The narrowly scoped adjustment in OpenJPEG's inverse DC stage keeps those values instead of clipping them. The wrapper removes the unsigned midpoint **before** float32 conversion, divides by 2²⁸, and the TypeScript layer applies the saved min/max with float32 rounding. This reproduced every exported sample bit-for-bit in the external 38-spectrum reference and controlled COSY and non-square NOESY matrices.

## Supported native dialect

Verified against Mnova 17.0.0-41178 saves and the supplied native reference document:

- Modern native Qt compatibility records with version-nine dimensional essentials.
- Uncompressed declared little/big-endian float32 1D real/complex arrays, and native JPEG 2000 compressed 1D arrays.
- Real-only processed 2D matrices, with distinct F2 and F1 calibration.
- Saved processed intensities, phase/baseline already reflected in them, nucleus, frequency, calibrated descending ppm axes, complete parameter Title/Comment, and multi-spectrum dataset membership.

Stack display order, gain, hidden rows, annotations, raw source replay and publication artwork are not restored. Complex/hypercomplex native 2D, higher dimensions, legacy serialization versions, and other compression dialects fail explicitly. Reader support does not imply native Mnova writing.

The optional local-reference tests read user files only when available outside the application source. They never upload or package those documents. Self-contained authored fixtures cover interleaving, both byte orders, exact compressed reconstruction, independent non-square F1/F2 calibration, JPEG shape checks, metadata, array framing, truncation, corruption and expansion limits.
